# Stone to Sand

Sandustry **0.6** mod. Stone normally breaks into nothing. With this on, **anything** that destroys a stone cell leaves a pile of sand: the laser, the drill, the void gun, or another mod that only makes some tool able to clear stone.

It does not take over that other mod's dig profile, so the two can run together.

Default is **6 sand grains per stone cell**. Change **Sand per stone cell** in the mod settings (1–16). Grains that do not fit in an empty cell are skipped.

## Install (Steam)

1. Switch to the **mods** branch if the Mods screen isn't in your build. In Steam: Sandustry → Properties → Betas. Use the branch that matches 0.6.
2. Download the zip, unzip, and rename `laser-stone-to-sand-main` to `laser-stone-to-sand`. `modinfo.json` must sit directly inside that folder.
3. Move it to:

   - Windows: `%APPDATA%\sandustry\mods\laser-stone-to-sand\`
   - Linux: `~/.config/sandustry/mods/laser-stone-to-sand/`
   - macOS: `~/Library/Application Support/sandustry/mods/laser-stone-to-sand/`
4. Launch Sandustry, open **Mods**, and enable **Stone to Sand**.
5. Break stone with whatever tool you use. Sand should spill out when the cell actually breaks, not on a hit that only chips it.

Microsoft Store / Game Pass builds can't load local mods.
